# LeaveFlowSE requirements

Raw user stories for **LeaveFlowSE**, the leave-management web application for WorkSmartSE (COMP3297A).

The stories, acceptance criteria, and non-functional requirements are in [requirements-raw.md](requirements-raw.md). They were taken from the course project specification and the Group 13 requirements note.

There is no application to run in this repository yet. Open `requirements-raw.md` to read the requirements.
