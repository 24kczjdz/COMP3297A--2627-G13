# LeaveFlowSE requirements

Raw user stories for **LeaveFlowSE**, the leave-management web application for WorkSmartSE (COMP3297A).

The stories, acceptance criteria, and non-functional requirements are in [requirements-raw.md](requirements-raw.md). They were taken from the course project specification and the Group 13 requirements note.

[build-prompt.md](build-prompt.md) is a copy-paste prompt for implementing that specification: the techniques and stack, the state machine and screens, and deployment to Cloudflare at the end.

There is no application to run in this repository yet. Open `requirements-raw.md` to read the requirements, or `build-prompt.md` to build from them.
